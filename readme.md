# HireSight AI

HireSight AI is a web-based platform that uses artificial intelligence to
streamline resume shortlisting and provide employee analytics for HR teams.

## 🚀 Features

- AI-powered resume scoring with explanations
- Skill match and experience evaluation
- Employee attrition risk analysis
- Skill gap identification
- Clean, modern SaaS-style UI

## 🧠 How It Works

1. HR uploads a job description and candidate resume
2. AI evaluates the resume against role requirements
3. Candidates receive an overall score with insights
4. HR dashboards show attrition risk and skill gaps

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript (Vanilla)
- AI-ready architecture (API integration possible)
